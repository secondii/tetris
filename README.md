# 俄罗斯方块 · TETRIS

一个单文件、离线可玩、支持手机触屏的俄罗斯方块。

打开 `index.html` 即可游玩，无需联网、无需安装任何依赖。

## 玩法

| 键盘 | 作用 |
| --- | --- |
| ← → | 左右移动（长按连发） |
| ↓ | 软降（+1 分/格） |
| ↑ / X | 顺时针旋转 |
| Z / Ctrl | 逆时针旋转 |
| 空格 | 硬降（+2 分/格） |
| C / Shift | 暂存（Hold） |
| P / Esc | 暂停 |
| R | 重开 |

手机端底部有 6 个按钮：◀ ▼ ▶ / ⟳ ⤓ ◫

## 特性

- 7-bag 随机：每 7 个方块必为 I/J/L/O/S/T/Z 各一次
- 幽灵投影、踢墙旋转、Hold 暂存、4 个 Next 预览
- 触底 0.5 秒锁定延迟，可微调
- 消行 100/300/500/800 × 等级，每 10 行升一级
- 响应式布局，适配桌面与手机竖屏，高分屏适配
- 切到后台自动暂停

## 部署到 Gitee Pages

1. 在 Gitee 新建仓库 `tetris`，**开源**，**不要**勾选初始化 README
2. 在本目录运行 `publish.ps1`，按提示输入仓库地址并推送
3. 打开仓库页面 → 服务 → Gitee Pages → 分支选 `master` → 启动
4. 访问 `https://<你的用户名>.gitee.io/tetris`
